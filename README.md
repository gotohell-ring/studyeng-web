# 여행 영어 — Windows 웹 1차 버전

## 실행

1. **가장 간단하게:** 이 폴더의 `index.html`을 Edge 또는 Chrome으로 엽니다. 설치·빌드·서버 없이 키보드로 전체 레슨과 복습을 진행할 수 있습니다.
2. **마이크 사용 권장:** `start.bat`을 더블클릭합니다. Python이 있으면 이 폴더를 `http://localhost:8765`로 열고, 없으면 `index.html`을 엽니다. 서버 창을 닫거나 `Ctrl+C`를 누르면 서버가 종료됩니다. 실행 위치는 상관없습니다.
3. 첫 실행에는 환영 → 선택 마이크 테스트 → T2 중급 선택 순서로 진행합니다.

샘플은 **유닛 1 · 체크인·수하물 · T2** 하나입니다. 나머지 유닛·T1·T3은 준비 중으로 표시합니다. 기본 드릴 25문항, 대본 대화 3턴, 선택 추가 연습 15문항입니다. 입력창은 항상 사용할 수 있으며 음성 인식이 실패하면 키보드로 자동 전환합니다.

## 저장과 백업

- 모든 기록은 현재 브라우저의 `localStorage` 키 `studyeng.v1` 하나에 저장합니다. 응답 제출, 결과 표시, 다음 문항 이동 때 즉시 저장하며 작성 중인 입력과 블록 배열도 보존합니다.
- 레슨을 닫으면 홈의 **이어하기**로 같은 문항 또는 이미 제출한 결과부터 재개합니다. 미니 대화도 현재 턴을 유지합니다.
- **파일 직접 실행과 localhost는 서로 다른 저장 공간**입니다. Edge와 Chrome도 기록이 공유되지 않습니다. 실행 방식을 바꿀 때는 설정에서 백업 내보내기 → 다른 실행 방식에서 가져오기를 사용하세요. `file://` 저장 정책은 브라우저에 따라 다릅니다.
- 손상·다른 버전의 데이터는 덮어쓰지 않습니다. 복구 화면에서 원본 다운로드, 백업 가져오기, 백업 후 초기화, 저장 없이 체험하기를 제공합니다. 지원하는 스키마는 버전 1이며, 알 수 없는 버전을 임의로 변환하지 않습니다.
- 저장이 차단되거나 공간이 부족해도 현재 창에서 학습할 수 있습니다. 안내 배너가 보이면 **설정 → 백업 내보내기**를 사용하세요. 브라우저를 닫기 전에 파일을 저장하세요.
- 가져오기는 유효성 검증 후 **현재 상태의 자동 백업 다운로드 + 전체 교체 확인**을 거칩니다. 진도 초기화는 **백업 다운로드 후 확인 2번**을 거칩니다. 백업에는 직접 입력한 답과 학습 기록이 포함됩니다.

### iPhone에서 저장하기
- **자동 저장**: 답을 낼 때마다 이 기기(브라우저 저장소)에 저장됩니다. 레슨·복습 화면 위의 **저장** 버튼은 입력 중인 답까지 포함해 즉시 저장하고 저장 시각을 알려 줍니다.
- **홈 화면에 추가 권장**: Safari 탭으로만 쓰면 오래 접속하지 않을 때 Safari가 사이트 데이터를 지울 수 있습니다. 공유 → **홈 화면에 추가**로 연 앱은 저장이 더 안정적입니다. Safari 탭과 홈 화면 앱은 저장 공간이 서로 다릅니다.
- **iCloud에 보관**: 설정 → **파일에 저장 · iCloud Drive** → 공유 시트에서 **파일에 저장** → iCloud Drive(또는 나의 iPhone) 선택. 복원은 설정 → 백업 가져오기에서 그 파일을 고릅니다. 웹은 iCloud에 자동 동기화할 수 없어서 이 방법으로 직접 보관합니다.

## 학습 규칙

- 점수·정규화·홈 추천은 `docs/design/core-spec.md`와 `score_ref.py`를 따릅니다. 정확 90점 이상, 거의 70점 이상, 다시 70점 미만입니다.
- 첫 **유효** 시도 점수가 기록입니다. 다시 해보기의 점수가 올라도 원래 점수·학습 수는 바뀌지 않습니다. 음성 결과 없음은 점수·학습 수를 만들지 않습니다.
- 드릴의 **내 답도 맞아요**는 개인 허용 답안을 저장하고 100점으로 번복합니다. 복습의 **내가 맞았어요**는 그날 그 카드의 평가만 원래 상태에서 Good으로 다시 적용하며 하루 한 번 가능합니다. 복습은 개인 허용 목록을 조회하지 않습니다.
- 복습은 포함된 `ts-fsrs 5.4.2`를 사용합니다. 새 카드 첫 출제는 다음 논리일 오전 4시, 하루 기본 한도는 새 10장·기존 복습 50장입니다. 일 경계와 연속일도 로컬 오전 4시를 기준으로 합니다.
- AI는 웹에서 사용할 수 없습니다. 롤플레이는 대본과 모범 답안 대조, 미션은 `successHints`의 연속 단어열 일치로 판정합니다. 점수가 낮은 대화 턴은 복습 카드가 됩니다.

## 음성과 단축키

- 마이크: `SpeechRecognition` 또는 `webkitSpeechRecognition`, 영어 `en-US`, 최대 15초, 첫 음성 없이 5초면 실패 처리합니다. 브라우저 인식기는 네트워크를 요구할 수 있습니다. 권한 거부·네트워크 오류·기능 미지원이면 키보드로 전환합니다. 실제 권한 창은 사용자가 허용해야 합니다.
- 읽어주기: 설치된 **로컬 영어 음성**을 우선하며, Edge에서 이름에 `Online`이 포함된 영어 음성도 사용할 수 있습니다. 온라인 음성은 네트워크가 필요할 수 있습니다. 영어 음성이 없으면 Windows 설정에서 영어 음성을 설치하거나 텍스트로 학습하세요. 자동 재생과 속도는 설정에서 바꿀 수 있습니다.
- 같은 읽어주기 안내는 탭의 브라우저 세션당 한 번 표시합니다. 상단 토스트는 4초 뒤 사라지고 누르면 닫힙니다. 세션 저장소가 차단되면 현재 페이지에서 중복을 막습니다.
- `Enter`: 확인/다음, `Esc`: 저장하고 닫기 확인, `Ctrl+Space` 또는 입력창 밖의 `M`: 말하기, `Ctrl+Enter`: 건너뛰기. 입력창의 `Shift+Enter`는 줄바꿈입니다.
- 다크 모드는 Windows/브라우저 설정을 따릅니다. 애니메이션 줄이기 설정도 반영합니다.

## 콘텐츠 재생성과 검사

저장소 어디서 실행하든 빌더 자체는 경로를 자동으로 찾습니다. 아래 명령은 저장소 루트에서 실행합니다.

```powershell
python tools/build_content.py
node web/tests/run.js
```

빌더는 `docs/design/sample/*.json`을 원본 `validate_ref.check()`로 검사하고 `js/content.js`를 생성합니다. 오류가 있으면 종료 코드 1이며 기존 생성 파일은 바꾸지 않습니다. 사용자 실행 때는 Python도 필요하지 않습니다.

Node 테스트는 정규화, 참조 채점 23건, 홈 규칙 21행, FSRS, 카드 중복·번복, 저장·복원·연속일, 전체 학습 흐름과 모든 화면 렌더링, 음성 이벤트 순서를 검사합니다. 토스트 수명·세션 중복 방지, 온라인 음성 선택, 단어 상태 표시, 홈 주 버튼 순서도 검사합니다. 화면 스크립트는 `index.html`의 로드 순서대로 검사합니다. 최소 가짜 DOM을 사용하며 실제 Edge/Chrome의 권한·음질·파일 다운로드 UX 검증을 대체하지 않습니다.

## 현재 검증 범위와 한계

- Node 검사와 콘텐츠 빌더 검증 완료. 개발 환경에서 실제 브라우저 자동 실행은 `spawn EPERM`으로 차단되어 **실제 Edge/Chrome 화면·마이크·더블클릭 및 배치 파일 실행은 미검증**입니다.
- 앱 코드에는 외부 요청, CDN, 웹 폰트, 로컬 JSON fetch, ES 모듈, npm 의존성이 없습니다. 음성 인식 엔진의 네트워크 사용 여부는 브라우저가 결정합니다.
- 브라우저가 로컬 저장을 지우면 백업 파일 없이 복구할 수 없습니다. 레슨 완료 때 자동 파일 다운로드는 하지 않으므로 설정 또는 완료 화면에서 주기적으로 백업하세요.
- iOS 전용 AI·배치 테스트·다른 유닛·학습 티어 자동 조정은 이번 웹 범위에 포함하지 않습니다.
