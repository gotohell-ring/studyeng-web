# 마켓 브리핑 대시보드 — 제작 프롬프트 (v0.2)

> 이 문서는 웹 대시보드 구현을 맡을 에이전트/개발자에게 그대로 전달하는 **마스터 프롬프트**입니다.
> `[추천]` 표시는 원 요구사항 외에 추가 제안된 항목입니다. 범위에서 빼려면 해당 줄만 지우면 됩니다.

---

## 0. 역할 & 목표

당신은 금융 데이터 시각화에 능숙한 프론트엔드 엔지니어 겸 UI 디자이너입니다.
**"아침 5분 안에 시장 전체를 파악할 수 있는"** 한국어 웹 대시보드를 만드세요.

- 사용자: 국내·미국 주식에 투자하는 개인 투자자 (한국어 사용)
- 사용 시점: 출근 전(미국장 마감 직후) / 장중 / 장 마감 후
- 핵심 원칙: **한 화면 요약 → 클릭 시 상세**, 숫자보다 **방향(↑↓)과 변화폭**을 먼저 보여줄 것

| 요약 규칙 | ① 결론(의견·목표가) ② 근거 2가지 ③ 리스크 1가지 — 총 3~4줄, 추측 금지·원문에 없는 수치 생성 금지 |

### 1-2. 주요 지수 (국내 · 미국 · 유럽)
| 지역 | 지수 |
|---|---|
| 국내 | KOSPI, KOSDAQ, `[추천]` KOSPI200 야간선물 |
| 미국 | S&P 500, NASDAQ Composite, Dow Jones, `[추천]` Russell 2000, 필라델피아 반도체(SOX) |
| 유럽 | Euro Stoxx 50, DAX, FTSE 100, CAC 40 |

- 표시: 현재가 · 전일 대비(%, 색상) · 미니 스파크라인(5일/1개월) · 장 상태(개장/마감/휴장)
- 색상 규칙: **한국식(상승=빨강, 하락=파랑)** 기본, 설정에서 국제식 전환 가능

### 1-3. 미국 국채 금리 (2년물 · 10년물)
- 현재 금리, 전일 대비 변화폭을 **bp 단위**로 표시 (1bp = 0.01%p)
- 방향 표시: ▲/▼ + 최근 1주·1개월 추세
- **장단기 스프레드**: $\text{Spread} = Y_{10Y} - Y_{2Y}$ (음수 = 역전, 경고 배지)
- `[추천]` 금리 변화 해석 라벨: Bull/Bear × Steepening/Flattening 4분면
  - 예: 2년↓·10년↓ 이고 2년 하락폭이 더 크면 → *Bull Steepening*

### 1-4. StockNow API 데이터
- 연결: StockNow MCP (읽기 전용 23개 도구, 심볼 형식 `EXCHANGE:CODE`, 예: `KS:005930`, `NASDAQ:TSLA`)
- 활용: 관심종목 시세, **기술적 지표**(RSI·MACD·이동평균), 공시/컨퍼런스콜/뉴스 근거 검색
- 제약: 무료 100회/일, Pro 2,000회/일 → **캐싱 필수**(시세 1~5분, 지표 1시간, 공시 1일)

### 1-5. SAVE 앱 정보
- SAVE(㈜파이브라인즈): 미국 증시 속보 · 기업 리포트 · 경제 지표 요약 · 투자 캘린더 제공
- ⚠️ **공개/오픈 API 없음** (2026-11 재조사: 앱스토어·공식 사이트·개발자 문서 어디에도 API 안내 없음)
- 대응 방안 (우선순위):
  1. **수동 입력**: 앱에서 공유 → 대시보드 "SAVE 메모" 입력창에 붙여넣기 → LLM이 태그·요약
  2. **동일 정보 대체 소스**: 경제 캘린더·속보는 StockNow 뉴스/공시 + 공개 경제 캘린더로 대체
  3. **제휴 문의**: 파이브라인즈에 데이터 제휴(API) 문의 → 확보 시 어댑터 교체
  - ❌ 앱 내부 API 리버스엔지니어링/스크래핑은 약관 위반 소지 → 하지 않음
- 표시: 속보 타임라인, 관심 키워드 하이라이트

## 4. 기술 요구사항
- 정적 웹(HTML/CSS/JS) 우선, 필요 시 Vite + React로 확장 / 차트: Lightweight Charts 또는 Chart.js
- 데이터 계층 분리: `adapters/`(리포트·지수·금리·StockNow·SAVE) → 공통 스키마 → UI
- 공통 스키마 예시:
  ```json
  { "id": "SPX", "name": "S&P 500", "region": "US", "value": 0, "change": 0, "changePct": 0, "asOf": "ISO8601", "source": "..." }
  ```
- API 키는 **클라이언트에 노출 금지** → 서버리스 프록시(Cloudflare Workers 등) 사용
- 모든 수치에 **출처·기준시각** 표기, 지연 데이터는 "지연 15분" 배지
- **데이터 지연 허용: 15분** → 실시간 스트리밍 불필요, 시세 폴링 주기 5~15분으로 충분 (API 호출량 절감)

### 4-1. LLM 추론 계층 (리포트 요약·번역·브리핑)
- 제공자: **OpenCode → DeepSeek API** (OpenAI 호환 `/chat/completions` 형식)
  - 엔드포인트·모델명은 환경변수로 분리: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`
  - 후보: OpenCode Zen 게이트웨이(`https://opencode.ai/zen/v1`) 또는 DeepSeek 직접(`https://api.deepseek.com/v1`) — 실제 사용 경로 확정 필요
- 작업별 프롬프트 템플릿 분리: `summarize_report_ko`, `translate_en_ko`, `daily_brief`, `tag_save_memo`
- 출력은 **JSON 스키마 강제** (의견·목표가·요약3줄·리스크·근거페이지), 파싱 실패 시 1회 재시도
- 비용 절감: 리포트 ID 기준 결과 캐싱(재요약 금지), 긴 PDF는 청크 요약 → 통합 요약
- 환각 방지: 숫자(목표가·실적)는 원문에서 정규식 추출값과 교차검증, 불일치 시 "확인 필요" 배지
- 실패 시: 마지막 캐시 값 + "업데이트 실패" 표시 (빈 화면 금지)

## 5. 콘텐츠 규칙
- 리포트 요약은 원문 근거 기반, 번역 시 숫자·고유명사 원문 유지
- 하단 고정 문구: "본 대시보드는 투자 참고용이며, 투자 판단의 책임은 투자자 본인에게 있습니다."
- 리포트 원문 전문 재게시 금지(저작권) → 요약 + 원문 링크만

## 6. 산출물 & 진행 순서
