# 마켓 브리핑 대시보드 — 제작 프롬프트 (v0.5)

> 이 문서는 웹 대시보드 구현을 맡을 에이전트/개발자에게 그대로 전달하는 **마스터 프롬프트**입니다.
> `[추천]` 표시는 원 요구사항 외에 추가 제안된 항목입니다. 범위에서 빼려면 해당 줄만 지우면 됩니다.

---

## 0. 역할 & 목표

당신은 금융 데이터 시각화에 능숙한 프론트엔드 엔지니어 겸 UI 디자이너입니다.
**"아침 5분 안에 시장 전체를 파악할 수 있는"** 한국어 웹 대시보드를 만드세요.

- 사용자: 국내·미국 주식에 투자하는 개인 투자자 (한국어 사용)
- 사용 시점: 출근 전(미국장 마감 직후) / 장중 / 장 마감 후
- 핵심 원칙: **한 화면 요약 → 클릭 시 상세**, 숫자보다 **방향(↑↓)과 변화폭**을 먼저 보여줄 것

### 1-3. 미국 국채 금리 (2년물 · 10년물)
- 현재 금리, 전일 대비 변화폭을 **bp 단위**로 표시 (1bp = 0.01%p)
- 방향 표시: ▲/▼ + 최근 1주·1개월 추세
- **장단기 스프레드**: $\text{Spread} = Y_{10Y} - Y_{2Y}$ (음수 = 역전, 경고 배지)
- `[추천]` 금리 변화 해석 라벨: Bull/Bear × Steepening/Flattening 4분면
  - 예: 2년↓·10년↓ 이고 2년 하락폭이 더 크면 → *Bull Steepening*

### 1-4. StockNow API 데이터 (✅ 2026-11-08 연결 검증 완료)

- 검증 결과: `get_technical_indicators(ARCX:SPY, NASDAQ:NVDA)` → 2026-11-06 기준 SMA·EMA·MACD·RSI14·골든/데드크로스 정상 수신
- 활용: 관심종목 시세, **기술적 지표**(RSI·MACD·이동평균), 실적·어닝콜·공시·뉴스 근거 검색(`search_evidence`)
- 제약

### 1-6b. 옵션 데이터 (신규)
| 시장 | 대상 | 소스 |
|---|---|---|
| 국내 | KOSPI200 옵션 | **사용자 제공 데이터** (형식 확인 후 어댑터 작성) |
| 해외(미국) | SPY, QQQ, SPX, NDX, 관심종목 | **무료 소스 다중 구성** (아래 표, 장애 시 자동 폴백) |

**해외 옵션 무료 소스 (우선순위 / 폴백 순서)**
| 순위 | 소스 | 키 | 지연·범위 | 제공 필드 | 제약 |
|---|---|---|---|---|---|
| 1 | **Cboe 지연 시세 JSON** `cdn.cboe.com/api/global/delayed_quotes/options/{SYM}.json` (지수는 `_SPX` 형식) | 불필요 | 15분 지연, 전 만기 체인 | Bid/Ask/Last, 거래량, **OI, IV, Greeks** | 비공식 공개 피드 → 형식 변경 위험, 과도한 호출 금지 |
| 2 | **Yahoo Finance 옵션체인** (`yfinance` 등) | 불필요 | 15분 지연 | Bid/Ask/Last, 거래량, OI, IV (Greeks 없음 → 직접 계산) | 비공식, 차단·형식 변경 위험 |
| 3 | **Massive(구 Polygon) Options Basic** | 무료 키 | **일별(EOD)** | 계약 목록, 일별 OHLCV | 분당 5회 |
| 4 | **MarketData.app 무료 키** | 무료 키 | 지연 | 체인·Greeks | 일 100회 (정책 변경 확인 필요) |

- 운영 방식: 07:00 배치 + 새로고침 + 장중 15분 캐시 / 주요 5~10개 기초자산만 수집해 호출량 최소화
- 정규화: 모든 소스를 공통 스키마로 변환 `{underlying, expiry, strike, type, bid, ask, last, volume, oi, iv, delta, gamma, asOf, source}`
- Greeks 미제공 소스는 Black-Scholes로 계산: $d_1=\dfrac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}}$, $\Delta_{call}=N(d_1)$

- Google Finance는 옵션 데이터를 제공하지 않음 → 위 소스로 별도 어댑터 구성
- 표시 지표
  - **Put/Call Ratio**: $\text{PCR} = \dfrac{\text{Put 거래량}}{\text{Call 거래량}}$ (미결제약정 기준도 병기)
  - **Max Pain**: $K^{*} = \arg\min_{K}\sum_{i}\big[\,OI^{C}_{i}\max(K-K_i,0) + OI^{P}_{i}\max(K_i-K,0)\,\big]$
  - 행사가별 미결제약정(OI) 막대그래프, 만기별 ATM IV(기간구조), IV 스큐(25Δ Put − 25Δ Call)
  - 이상 거래: 거래량/OI 비율 급증 계약 Top 10
- 갱신: 07:00 배치 + 새로고침 시, 미국 옵션은 장중 15분 캐시
- 데이터 라이선스상 **재배포 금지** 가능성 → 개인용 대시보드로 한정

### 1-7. AI 상호작용 — 클릭 요약 & 사이드 채팅 (DeepSeek)
- **클릭 요약**: 대시보드의 모든 카드(리포트·지수·금리·종목·SAVE 메모)를 클릭하면
  우측 패널 상단에 DeepSeek 요약이 스트리밍 표시
  - 입력 컨텍스트 = 해당 카드의 원본 데이터(JSON) + 관련 리포트 본문/지표
  - 출력 = 핵심 3줄 · 의미(왜 중요한가) · 체크포인트 · 출처
- **사이드 채팅창**: 화면 우측 고정 패널(모바일은 하단 시트)
  - 클릭한 카드가 **대화 컨텍스트로 자동 첨부**(칩 형태, 여러 개 누적 가능, X로 제거)
  - 자유 질문 → DeepSeek 답변, 필요 시 **도구 호출(function calling)** 로 StockNow MCP 조회 후 답변
    (예: "엔비디아 RSI 지금 과매도야?" → `get_technical_indicators` 호출 → 근거와 함께 답변)
  - 답변에는 사용한 데이터의 출처·기준시각 표기, 데이터에 없는 내용은 "확인 불가"로 답할 것
- **세션 구조**
  - 1 세션 = 하루치 대시보드 데이터 스냅샷 + 해당 날짜의 채팅 기록
  - 세션 ID 예: `2026-11-09` / 채팅 기록은 서버(KV/DB)에 저장, 새로고침해도 유지
  - 대화가 길어지면 이전 대화를 요약해 컨텍스트 압축(토큰 절감)
- 스트리밍(SSE) 응답, 생성 중 "중지" 버튼, 답변 복사 버튼


## 4. 기술 요구사항
- 정적 웹(HTML/CSS/JS) 우선, 필요 시 Vite + React로 확장 / 차트: Lightweight Charts 또는 Chart.js
- 데이터 계층 분리: `adapters/`(리포트·지수·금리·StockNow·SAVE) → 공통 스키마 → UI
- 공통 스키마 예시:
  ```json
  { "id": "SPX", "name": "S&P 500", "region": "US", "value": 0, "change": 0, "changePct": 0, "asOf": "ISO8601", "source": "..." }
  ```
- API 키는 **클라이언트에 노출 금지** → 서버리스 프록시(Cloudflare Workers 등) 사용
- 모든 수치에 **출처·기준시각** 표기, 지연 데이터는 "지연 15분" 배지
- **데이터 지연 허용: 15분** → 실시간 스트리밍 불필요, 시세 폴링 주기 5~15분으로 충분 (API 호출량 절감)

### 4-1. LLM 추론 계층 (리포트 요약·번역·브리핑)
- 모델: **추론형(thinking) DeepSeek** — 후보 `deepseek-v4-pro`(thinking 모드) / 구버전 `deepseek-reasoner`는 단종 예정 보도 → 실제 ID는 OpenCode `/models`로 확인 후 `LLM_MODEL`에 설정
  - 추론 과정(reasoning_content)은 화면에 기본 접힘으로만 표시, 최종 답변만 대화 기록에 저장(토큰 절감)
- 제공자: **OpenCode API의 DeepSeek 모델** (OpenAI 호환 `/chat/completions`, 스트리밍·function calling 사용)
- 용도: ① 리포트 요약·번역(07:00 배치) ② 카드 클릭 요약 ③ 사이드 채팅 답변
  - 엔드포인트·모델명은 환경변수로 분리: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`
  - 후보: OpenCode Zen 게이트웨이(`https://opencode.ai/zen/v1`) 또는 DeepSeek 직접(`https://api.deepseek.com/v1`) — 실제 사용 경로 확정 필요
- 작업별 프롬프트 템플릿 분리: `summarize_report_ko`, `translate_en_ko`, `daily_brief`, `tag_save_memo`
- 출력은 **JSON 스키마 강제** (의견·목표가·요약3줄·리스크·근거페이지), 파싱 실패 시 1회 재시도
- 비용 절감: 리포트 ID 기준 결과 캐싱(재요약 금지), 긴 PDF는 청크 요약 → 통합 요약
- 환각 방지: 숫자(목표가·실적)는 원문에서 정규식 추출값과 교차검증, 불일치 시 "확인 필요" 배지
- 실패 시: 마지막 캐시 값 + "업데이트 실패" 표시 (빈 화면 금지)

## 5. 콘텐츠 규칙
- 리포트 요약은 원문 근거 기반, 번역 시 숫자·고유명사 원문 유지
- 하단 고정 문구: "본 대시보드는 투자 참고용이며, 투자 판단의 책임은 투자자 본인에게 있습니다."
